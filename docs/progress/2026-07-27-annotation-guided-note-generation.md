# 2026-07-27：批注驱动的解释型笔记生成完成

## 目标

笔记不应泛化总结整篇论文，也不应只是改写用户高亮。当前生成口径调整为：

> 标注决定写什么，附近原文决定理解边界，大模型负责解释、关联和组织。

四条边界：

1. 每个正文主题必须由用户选中的真实批注触发；
2. 每个有原文上下文的主题必须包含解释或有依据的跨批注综合，不能只有高亮复述；
3. 没有用户评论时不得虚构“用户认为”或“我的理解”；
4. 用户问题必须保持为问题，不能无依据地改写成确定结论。

## 实现

- 生成请求只包含已选主题对应的 Evidence，未选批注不再发送到笔记生成阶段；
- 补充要求只能调整已选主题的解释角度和详略，不能替代真实批注；
- 后台内容映射增加 `content_role`、`focus_topic_ids` 和 `annotation_ids`；
- 本地校验新增主题覆盖、未选 Evidence、机械复述、跨批注综合、用户观点和问题保留检查；
- 检测到违反边界时，将具体错误交给模型审查阶段进行校正。
